# Resources

This directory is intended to organize reference material, supporting documents, and auxiliary files associated with the FVS theory work.

---

## Included material

The repository root currently contains the main reference and supporting assets, including:

- `../fvs(ftfsi)3.pdf`
- `../fvs_up6_new3particle_blackh.pdf`
- `../fvs_up7_new3particle_blackh.pdf`

These files remain in the root of the repository to preserve source continuity while being discoverable through a more formal references section.

---

## Recommended usage

- Use the PDF files as supporting technical references.
- Use the manuscript and prediction files for the formal theory and derivations.
- Use this directory as the repository-level landing point for non-core supporting material.
