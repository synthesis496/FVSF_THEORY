# FVS Overview

## What is FVS?

FVS stands for Fibo Vortex Spiral Space. The theory presented in this repository is a geometric and temporal framework designed to relate a compact set of structural constants to a series of physical quantities and cosmological ratios.

The theory centers on a few key ideas:

- the use of lattice-based symmetry structures such as E8×E8 and SO(32)
- the golden ratio φ as a recurring scaling parameter
- parity alternation and zero-sum balancing relations
- a temporal field framework described as Fibonacci time dynamics

---

## Core pillars

The manuscript organizes the theory around four main pillars:

1. Golden ratio scaling
2. Alternating parity structure
3. Gauge-commutator invariance
4. Zero-sum parity integration

Together, these are presented as a self-stabilizing framework intended to explain how a compact geometric structure could generate observable physical relations.

---

## Core numerical themes

The manuscript highlights derived relations such as:

- inverse fine-structure constant
- dark matter fraction
- recoil energy scale
- proton-to-electron mass ratio
- cosmological constant scaling
- tensor-to-scalar ratio

These are discussed as structural outputs of the same foundational model rather than isolated numerical fits.
